SHOCK GRID · Δ P&L ($)
ROWS = SPOT SHOCK, COLUMNS = ADDITIVE PARALLEL VOL SHOCK IN POINTS, EVALUATED AT THE HORIZON SET ON THE LEFT. THE SHOCK IS APPLIED TO EVERY LEG'S VOL EQUALLY — THIS IS A FLAT-SURFACE ASSUMPTION AND IT IS WRONG IN THE DIRECTION THAT MATTERS: REAL EQUITY SKEW STEEPENS WHEN SPOT FALLS, SO DOWNSIDE CELLS UNDERSTATE A LONG-PUT POSITION'S GAIN AND UNDERSTATE A SHORT-PUT POSITION'S LOSS.

MODEL ASSUMPTIONS, STATED NOT BURIED. European exercise only — American early exercise is not modelled and this page will misprice deep-ITM American puts. Constant volatility per leg; no smile, no term structure, no stochastic vol. Constant continuous rate and dividend yield. No borrow cost, no financing spread, no transaction cost, no bid-ask. Black-76 is reached by setting q ≡ r, which is exact for a futures underlier. Greeks are analytic first/second-order sensitivities, valid locally — they are not a substitute for a full revaluation, which is what the shock grid does instead.
